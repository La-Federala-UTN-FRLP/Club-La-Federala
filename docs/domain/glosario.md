# Glosario del dominio

| Término | Definición | Observaciones |
|---|---|---|
| Lote | Unidad vendible o espacio común. | Se vincula a ubicación, fracción, propietario y operaciones. |
| Fracción | Agrupación territorial de lotes. | Número único. |
| Persona | Persona física o jurídica registrada. | Propietario, comprador, cliente, inquilino o familiar. |
| Inmobiliaria | Agencia asociada. | Opera clientes, reservas y prioridades propias. |
| Reserva | Bloqueo temporal de un lote para un cliente. | Puede expirar o consumirse en una venta. |
| Venta | Operación comercial de un lote. | Incluye comprador, pagos y archivos. |
| Plan de pago | Plan versionado de cuotas de una venta. | Tiene cuotas y pagos registrados. |
| Prioridad | Derecho temporal sobre un lote. | De inmobiliaria o club. |
| Promoción | Precio promocional temporal. | Guarda precio y estado previos. |
| Archivo | Documento o imagen de lote/venta. | Boleto, escritura, plano, imagen u otro. |
| Estado operativo | Baja lógica de una entidad. | `OPERATIVO` o `ELIMINADO`. |
| Rol | Perfil de acceso. | Administrador, gestor, inmobiliaria o técnico. |
